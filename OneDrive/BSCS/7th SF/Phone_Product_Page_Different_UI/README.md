# iPhone Product Page (iStore Hub)

A responsive web application featuring an interactive product page with dynamic form handling, real-time age-based discount calculation, and sleek UI styling.

## How to Run the Project

You can view the live project directly here: 
 https://tawankou.github.io/iStore-Hub/


Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The assignment will open automatically in your default web browser.

**Tech Stack:** HTML5, CSS3, JavaScript (ES6)

---
*Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.*
